# ورّاق — استوديو الكتب التفاعلية ثلاثية الأبعاد

موقع عربي تجريبي لعرض الكتب بتقليب الصفحات، ونماذج هندسية 3D، وصوت، وأسئلة تفاعلية.

## تشغيل الموقع
**بعد تفعيل GitHub Pages**، افتح:
https://s023007.github.io/interactive-3d-book-studio/

### ميزات الإصدار 0.1
- افتح ملف PDF من الجهاز، دون رفعه إلى الخادم (حتى 65 ميجابايت وأول 120 صفحة).
- تقليب الصفحات عبر مكتبة StPageFlip.
- قطاع دائري متغير الزاوية، مكعب، كرة، أسطوانة، مخروط — كلها مجسمات قابلة للدوران والتكبير بواسطة Three.js.
- نطق شرح عربي بحسب دعم المتصفح أو تشغيل تسجيل صوتي محلي مؤقت.
- أسئلة من ثلاثة خيارات تُحفظ محليًا في المتصفح.
- تصميم يدعم الهواتف والعربية RTL.

### النشر
افتح GitHub → Settings → Pages → Build and deployment.
اختر **Deploy from a branch**, ثم **main** و**/(root)** واضغط **Save**.
يحتاج أول نشر إلى نجاح إعداد Pages مرة واحدة.

### حدود النسخة
هذا نموذج أولي للتجربة وليس بديلًا مكتملًا عن Heyzine/Kotobee. المجسمات تظهر في نافذة تفاعلية مرتبطة بالصفحة، وليس داخل محتوى PDF الأصلي. لا توجد حسابات أو تخزين سحابي أو مزامنة، وتحتاج المكتبات إنترنت. لا تحفظ الملفات الصوتية بعد إعادة تحميل الصفحة. يرجى احترام حقوق المؤلف.
