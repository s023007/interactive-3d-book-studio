# لُمى تقود المشهد

تخطو لُمى نحو منتصف المسرح وتشير بيدها لتقديم المسألة. تتتابع قطع المعادلة، ثم تخرج حاملات الإجابات من جهة لُمى وتتوزع فوق الخيارات. عند طلب التلميح تلتفت وتشير، وعند النجاح تحتفل. يمكن إعادة تقديم السؤال بلمس لُمى أو استخدام زر الإعادة في الفقاعة. تبقى الاختيارات متاحة باللمس ولوحة المفاتيح، وتظهر العناصر مباشرة عند تفعيل تقليل الحركة.

## الصوت

وضع الصوت الافتراضي يشغّل التسجيل المرفق لكل عبارة ويعرض النص عند غيابه. يختار المستخدم من إعدادات الصوت نطق الجهاز الاصطناعي إذا أراده. لتجربة صوت بشري، افتح إعدادات الصوت على العبارة المطلوبة، ثم سجّل أداءها أو أرفق ملفًا مصرحًا باستخدامه. تبقى التسجيلات المرفقة في جلسة الصفحة. يتطلب نشر أداء بشري موحد لكل المشاهد تسجيلات مرخصة لكل العبارات.
