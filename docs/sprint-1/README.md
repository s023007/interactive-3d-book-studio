# ورّاق · مراجعة الجولة الأولى

كشف اختبار النسخة الأصلية قصّ عنوان لوحة السؤال في المقاسات الأربعة. كشفت مراجعة التنفيذ أن مؤقت المكافأة يمكن أن ينقل اللاعب قبل قراءة الشرح، وأن الخريطة تعرض النجوم في أول الخانات بصرف النظر عن السؤال الذي كسبت فيه النجمة. كانت خيارات التسجيل مرتبطة بالمشهد بكامله، ولذلك كان من الممكن تشغيل تسجيل السؤال عند سماع التلميح.

## التشغيل والتحقق

يتطلب سير الاختبارات Node.js 24. شغّل `npm ci` ثم `npx playwright install chromium` و`npm test`. لتشغيل نسخة محلية، استخدم `npm run serve` وافتح `http://127.0.0.1:4173/adventure.html`. يمكن اختيار Chromium مثبت مسبقًا بتعيين `WARRAQ_CHROMIUM` إلى مساره. يستخدم الاختبار حزمة Three.js المطابقة لإصدار رابط التحميل في الصفحة ويعزلها عن اتصال CDN. ينشر فحص GitHub Actions اللقطات ضمن مرفقات تشغيل الاختبار.

تغطي الاختبارات إكمال مغامرة كل صف، والتلميح وتصحيح الإجابة، وإعادة اللعب، وتخصيص اللون، ومواقع النجوم، وغياب WebGL أو الميكروفون أو الصوت العربي. تخضع المقاسات ٣٦٠×٨٠٠ و٣٩٠×٨٤٤ و٧٦٨×١٠٢٤ و١٤٤٠×٩٠٠ لاختبار تخطيط ولقطات Chromium. قياس الأداء ووضوح الصوت على هاتف Android فعلي يتطلب جهازًا متاحًا.

## تسجيل العربية

من زر الميكروفون، اقرأ العبارة المعروضة وسجّلها أو أرفق ملفًا مسموحًا باستخدامه. اختر التسجيلات البشرية وجرّب التشغيل ثم احفظ الاختيار. لكل سؤال أو تلميح أو مكافأة عبارتها، وتبقى الملفات في ذاكرة الصفحة. يتاح نطق الجهاز الاصطناعي إذا كان صوت عربي مثبتًا ومتاحًا للمتصفح. تظهر العبارة نصيًا عند تعذر الصوت. لا توجد تسجيلات ممثلين ضمن المشروع.

## إضافة محتوى دراسي لاحقًا

يحمل كل صف معرّفًا وعنوانًا وموضوعًا، وتحمل كل مسألة معرّفًا فريدًا ونصًا وصيغة رياضية وخيارات وفهرس الإجابة الصحيحة وتلميحًا وشرحًا. عند إضافة الاستيراد، تُفحص الحقول المطلوبة وتفرّد المعرّفات وصلاحية فهرس الإجابة قبل إتاحة الحزمة، ثم يراجع معلّم صحة المحتوى وعرض الصيغ على الهاتف. تسجّل جهة المحتوى مصدر كل مسألة وترخيصها، ويُقبل محتوى الكتب بعد التحقّق من حق استخدامه. الحزمتان الحاليتان أمثلة أصلية.
