# مخطط تحويل رسوم الكتب إلى تجارب ثلاثية الأبعاد

## ما الذي يعمل الآن؟
- الدخول من قارئ الكتاب عبر زر **شرح رسمة هذه الصفحة** لنقل صورة الصفحة إلى مختبر الرسومات.
- رفع صورة JPG/PNG أو كتاب PDF من الجهاز، واختيار الصفحة وتحديد جزء من الرسم بالسحب.
- اختيار نوع هندسي يدوي وإظهار نموذج 3D قابل للدوران والتكبير.
- تمثيل تعليمي بسمك افتراضي لمنطقة مظللة بين منحنيين، مع شرح صوتي عربي.
- حقل ربط اختياري بخدمة رؤية ذكاء اصطناعي خارجية؛ **هذه الخدمة ليست مفعلة افتراضيًا**.

## التمييز العلمي
الصور الثنائية لا تحدد هندسة ثلاثية الأبعاد وحيدة. عند رسم منطقة بين منحنيين، إضافة عمق وهمي تعني فقط **إظهار المنطقة كصفيحة**؛ لا تعني حساب حجم الدوران أو التكامل الثلاثي. يجب أن يراجع المعلم معادلات الرسم، وحدوده، وتسميات المحاور قبل اعتماد المجسم.

## كيف نفعّل تحليل الرسوم تلقائيًا؟
المستودع يتضمن نموذج Backend اختياري في `worker/index.js` لخدمة Cloudflare Workers. 
يستدعي نموذج رؤية عن طريق OpenAI API ويعيد كائن JSON قابلًا للتحقق يحدد:
- نوع الرسم (منطقة بين منحنيين / قطاع / مجسم بسيط / غير معروف).
- شرحًا عربيًا موجزًا.
- درجة ثقة.
- عينات عددية للمنحنيين إذا كانت المعادلات والمجال مقروءين.

### متطلبات تفعيل الخادم (من صاحب الحساب فقط)
1. أنشئ حسابًا لدى Cloudflare وWorker جديدًا (يمكن استخدام واجهة الويب).
2. انسخ كود `worker/index.js` إلى Worker وانشره.
3. أضف الأسرار عبر **Settings → Variables and Secrets**:
   - `OPENAI_API_KEY`: مفتاح من OpenAI Platform، وليس اشتراك ChatGPT.
   - `WARRAQ_ACCESS_CODE`: رمز قوي خاص بالمطور/المعلم، لا يقل عن 16 حرفًا، وليس مفتاح OpenAI.
4. اضبط متغير `ALLOWED_ORIGIN` إلى `https://s023007.github.io`.
5. افتح مختبر الرسومات، اختر **تحليل آلي**، وضع رابط Worker الذي حصلت عليه من Cloudflare مع `/analyze`، ثم أدخل رمز الدخول وأرسل صورة.
6. اختبر بالصور التعليمية غير الحساسة أولًا. لا تدخل مفتاح OpenAI في GitHub أو كود الموقع.

**تنبيه تشغيلي:** رمز الدخول هذا مناسب لمشروع تجريبي للمعلم وحده. قبل إتاحة الخدمة على نطاق واسع يجب إضافة تسجيل الدخول، حدود الاستخدام والمعدل (rate limits)، ووسيلة حماية من الاستغلال مثل Cloudflare Turnstile، ومراقبة كلفة طلبات API.

### الخصوصية
في الوضع اليدوي لا تغادر الصور المتصفح. عند الضغط على **تحليل الصورة** في الوضع الآلي، ستُرسل الصورة المقتطعة إلى Worker ثم إلى نموذج الرؤية. يلزم موافقة صاحب الحق عند استخدام صور الكتب، ولا ينبغي إرسال بيانات الطلاب الشخصية.

### ما لا يفعله النظام حتى الآن
- لا يحوّل **أي** صورة في أي كتاب إلى 3D بشكل مضمون.
- لا يستخرج بدقة جميع أنواع الدوال والتخطيطات والمجسمات من صورة واحدة.
- لا ينشئ أصول 3D واقعية من صور الحيوانات أو الأعضاء أو الآلات. لهذه الفئة نحتاج مسارًا آخر مثل Meshy Image-to-3D وإظهار ملفات GLB، مع مراجعة النتائج.
- لا ينشئ شرحًا صوتيًا اصطناعيًا فائق الجودة بمفرده؛ يستخدم الآن نطق المتصفح.

## المرحلة التالية
1. تفعيل Worker باعتماد صاحب الحساب، مع حماية التكاليف.
2. إضافة نماذج متخصصة لكل نوع رسم (منحنيات، أجسام دوران، أشكال هندسية، علوم).
3. لوحة مراجعة لإقرار المعادلات قبل البناء.
4. تصدير مشهد GLB وربطه بالصفحة في الكتاب.
5. تحويل الصور الواقعية من خلال خدمة Image-to-3D منفصلة مع تنبيه إلى عدم اليقين.
