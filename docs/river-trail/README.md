# أثر عند النهر

هذه أول جولة ثلاثية الأبعاد لمسار المغامرات. يبدأ الراكون في السهل، ويتحرك نحو أثرين على طريق النهر. يجرب اللاعب قطعة خشبية عند قفل الجسر. أربع خانات من أصل ثمان مركبة، ونحتاج إلى خانتين ليصبح المجموع ستة أثمان، أي ثلاثة أرباع. يمكن تجربة القطع الأقصر والأطول وقراءة أثر المحاولة. بعد فتح الجسر يسير الراكون إلى موقع التصوير وتظهر صورة الظبي في دفتر الرحلة.

## التشغيل

شغّل `npm ci` ثم `npm run serve`. افتح `http://127.0.0.1:4173/river-trail.html`. يمكن أيضًا الوصول إليها من شاشة اختيار المغامرة. يدعم المستوى اللمس في المشهد أو أزرار الاتجاهات، والأسهم أو WASD على لوحة المفاتيح. مفتاح المسافة أو زر المهمة يوجّه الراكون نحو العلامة النشطة. يوجد مفتاح مستقل لصوت البيئة.

## الأصول والصوت

الراكون والظبي والأشجار والنهر والجسر مجسّمات وخامات أصلية مولّدة داخل Three.js. حركة الماء محسوبة آنيًا. أصوات الماء والطيور والخطوات والمكافأة مولّدة بواسطة Web Audio، ويتغير مستوى صوت الماء مع المسافة. تعتمد الجولة على تعليمات مكتوبة.

## الحفظ والاختبار

يحفظ المتصفح فتح الجسر والصورة بعد التقاطها. تُحذف نقطة الاستئناف عند بدء الرحلة من جديد. لقياس رحلة اللعب آليًا، شغّل `npx playwright install chromium` ثم `npm test -- tests/river-trail.spec.js`. يختبر الملف مقاسين للهاتف وسطح المكتب، والقطع القصيرة والطويلة، والعبور وحفظ الصورة، ولوحة المفاتيح والصوت. ما زال قياس الأداء على هاتف Android فعلي وتقييم المحتوى داخل الصف بحاجة إلى اختبار ميداني.
