# معاينة الثعلب والصوت

المجسم هو الثعلب من [عينة Vuena المجانية](https://vuena.itch.io/blocky-pets-free)، إصدار 3.1، بترخيص CC0. نسخة الترخيص الأصلية في مجلد المجسم. يحتوي ملف GLB على اثنتي عشرة حركة وعظمة فك مستقلة ومستويين من التفاصيل. تُعرض النسخة الهندسية الأخف في المعاينة.

تشغّل المعاينة حركتي الانتظار والمشي من الملف. تُحدّد زاوية فتح الفك من حركة النداء الأصلية، وتتحكم شدة التسجيل في مقدار الفتح عبر Web Audio. هذا اختبار لمزامنة الفك مع شدة الصوت. اختبار مخارج الحروف العربية يحتاج تسجيل أداء فعليًّا وتحريكًا أدق.

لتجربة الصفحة محليًا، شغّل `npm ci` ثم `npm run serve` وافتح `http://127.0.0.1:4173/fox-preview.html`. اختر تسجيلًا للجملة الظاهرة واضغط «شغّل التسجيل». يبقى التسجيل في المتصفح.

[لقطة الهاتف](fox-mobile.png)

## مهمة الربع الناقص

افتح «العب مع الثعلب: الربع الناقص» من شاشة اختيار المغامرة. تُظهر الصدفة نصفًا مقسومًا إلى ربعين. اختر قطعة من الخيارات الثلاثة. يعطي الثعلب تلميحًا عند اختيار قطعة أكبر من اللازم، وعند اختيار الربع يكتمل الرسم وتفتح البوابة. يمكن إعادة الجولة بلوحة المفاتيح أو اللمس. تبقى المهمة الرياضية قابلة للعب عند تعذّر تحميل العرض الثلاثي الأبعاد. تظهر أدوات الصوت والمشي تحت عنوان «الصوت وحركة الثعلب».
